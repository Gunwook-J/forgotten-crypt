# 잊혀진 묘역 · The Crypt of the Damned

A self-contained, mobile-friendly (iPhone Safari) dungeon-crawler game. Single HTML file, no external dependencies.

**Play:** https://gunwook-j.github.io/forgotten-crypt/

- Desktop: WASD / arrow keys to move, mouse or keys to attack
- iPhone: on-screen HUD and touch controls (add to Home Screen for full-screen play)
