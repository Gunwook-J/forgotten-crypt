# 잊혀진 묘역 · The Crypt of the Damned

A self-contained, mobile-friendly (iPhone Safari) dark-fantasy dungeon crawler.
Single HTML file, no external dependencies — the whole game, art and audio included.

**Play:** https://gunwook-j.github.io/forgotten-crypt/
**Quick play (no Pages setup):** https://raw.githack.com/Gunwook-J/forgotten-crypt/main/index.html

## 조작
- **PC**: WASD / 방향키 이동, 마우스 클릭 이동·공격, `1~5` 스킬·포션, `I` 소지품, `C` 캐릭터, `Tab` 지도, `Esc` 일시정지
- **iPhone**: 왼쪽 조이스틱 이동, 오른쪽 버튼 공격·스킬·포션 (홈 화면에 추가하면 전체 화면)

## 이번 버전
- 디아블로 1 분위기: 좁고 따뜻한 횃불 시야, 차가운 석조 그림자, 균열·피 웅덩이·해골 더미·철창·석조 기둥
- 픽셀 아트 액터: 전사/도적/마법사와 해골·시체·임프·망령·다크 로드 (걷기 8프레임, 대기, 공격 모션)
- 피격 경직·플래시, 사망 시 쓰러져 바닥에 유해가 남는 연출
- iPhone 탭 전환·새로고침에도 진행이 남는 localStorage 자동 저장 / 이어하기
